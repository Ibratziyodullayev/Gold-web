# 💎 Aurum Gold — Luxury Italian Gold & Diamond Boutique

> **18K (750°) Italiya Oltini & GIA Sertifikatlangan Brilliantlar**  
> Toshkent, Mirabad Avenue dagi flagman zargarlik butigi uchun yaratilgan yuqori konversiyali, eksklyuziv "White Luxe" veb-platformasi.

---

## ✨ Loyiha haqida (About The Project)

**Aurum Gold** — Toshkentning nufuzli auditoriyasi uchun mo'ljallangan, Cartier va Bulgari standartlari darajasidagi nozik va hashamatli dizayn asosida yaratilgan veb-sayt. Sayt tashrif buyuruvchilarga kolleksiyani to'liq ko'rish, taqinchoqlar detallari bilan tanishish va to'g'ridan-to'g'ri VIP konsyerj bilan bog'lanish imkonini beradi.

### 🌟 Asosiy Xususiyatlar:
- **White Luxe Estetikasi**: Issiq fil suyagi (ivory), och oltin (champagne gold) va nozik kontrastlar bilan boyitilgan premium ko'rinish.
- **Ikki Tilli Tizim (UZ / RU)**: Sahifa qayta yuklanmasdan o'zbek va rus tillari o'rtasida bir zumda almashish.
- **To'liq Ekranli Mahsulot Ko'rinishi (Full-screen Product Modal)**:
  - Har bir zargarlik buyumi uchun mos va sifatli fotogalereya (katta burchaklar, detallar).
  - Aniq texnik parametrlar (Oltin probasi: 750° / 18K, vazni, brilliant karati, tozaligi va kesimi).
  - Davlat Probir Palatasi tamg'asi va xalqaro GIA sertifikati kafolatlari.
  - To'g'ridan-to'g'ri Telegram orqali oldindan to'ldirilgan so'rov yuborish, qo'ng'iroq qilish va butikda VIP ko'rishga yozilish tugmalari.
- **Interaktiv Kalkulyator & Filtrlash**: 18K oltin narxi bo'yicha shaffof hisob-kitob, toifalar (Uzuklar, Bo'yinbog'lar, Ziraklar, Bilaguzuklar) bo'yicha tezkor saralash.
- **Interaktiv Lokatsiya**: Mirabad Avenue dagi butik joylashuvi, Yandex Maps va Google Maps havolalari.

## 🛠 Texnologiyalar (Tech Stack)

- **HTML5 & Vanilla CSS3**: Toza arxitektura, tez yuklanish, zamonaviy CSS Custom Properties (CSS variables) va Flexbox/Grid.
- **Vanilla JavaScript**: Tashqi kutubxonalarga bog'liq bo'lmagan, tez va barqaror DOM boshqaruvi.
- **Fontlar**: Google Fonts (`Cinzel` — hashamatli serif shrift, `Plus Jakarta Sans` — o'qilishi qulay sans-serif).
- **Icons**: Lucide Icons.

## 🚀 Loyihani ishga tushirish (Local Run)

Loyihani kompyuteringizda ishga tushirish uchun:

1. Repozitoriyani klon qiling:
   ```bash
   git clone https://github.com/Ibratziyodullayev/Gold-web.git
   cd Gold-web
   ```

2. Saytni brauzerda oching:
   - `index.html` faylini istalgan brauzerda (Chrome, Safari, Edge) to'g'ridan-to'g'ri ikki marta bosib ochishingiz mumkin, yoki
   - Lokal server orqali ishga tushirish:
     ```bash
     python3 -m http.server 3000
     ```
     va brauzerda `http://localhost:3000` manziliga kiring.
